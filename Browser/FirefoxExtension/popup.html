What still stops capture

    Private windows (optional)

    Normal-window capture does not need private access. To include private windows, open about:addons, choose Extensions in the sidebar, then ProxyMaxx > Details. Set Run in Private Windows to Allow.

    Without this access, ProxyMaxx does not select routes for private requests. An existing Firefox or system proxy can still carry private traffic.
