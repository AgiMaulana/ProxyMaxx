Traffic inspection

A debugger built around the flow.

The live table keeps method, status, host, path, size, duration, and client visible. Select a row to read request and response headers, formatted or raw bodies, timings, and decryption state.

HTTPS MITM
A local root CA signs per-host certificates for traffic you choose to decrypt.
WebSockets
Text, binary, and control frames stay attached to the upgrade flow.
Copy as cURL
Reproduce any captured request from the inspector or table context menu.

Local Override

Swap the server response without changing app code.

Match a URL by contains, wildcard, regular expression, or exact value. Serve a file or directory, add a delay, and share a complete test setup as a ZIP bundle with its response files.

  • First matching rule wins
  • Missing local files fall through to the remote server
  • Import, preview, activate, and export bundles from the app or CLI

Beyond the Mac

Capture browsers, emulators, and devices.

A SOCKS5 listener, Chromium extension, and Android setup guide route traffic into the same inspector.

Android setup in one click

Install the CA as a system certificate, set the emulator proxy, and launch the bundled tunnel. Google APIs and Google Play emulator images are supported.

Browser companions

Apply the proxy through browser proxy APIs in Chromium and Firefox and see which capture blocker remains, including CA trust or loopback.

Scriptable engine

proxymaxx-cli serves the proxy, lists captured flows with filters, and stops a detached session from shell scripts or agents.

Install

Run ProxyMaxx on macOS 14 or later.

Homebrew is the shortest path. The tap's cask clears the quarantine attribute so the app opens without a Gatekeeper warning.

Prefer a disk image? Download the latest release, drag ProxyMaxx to Applications, then follow the release notes for the one-time quarantine command.

Terminal 
brew tap agimaulana/proxymaxx
brew trust --tap agimaulana/proxymaxx
brew install --cask agimaulana/proxymaxx/proxymaxx
